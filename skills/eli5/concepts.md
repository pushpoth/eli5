# From an idea to a concept

A concept is three things: **an object**, **what the pointer does to it**, and
**what the read-out says**. It fits on one line. If it does not, it is not ready.

## The object is the explanation

Invent a real thing whose working *is* the idea. Not a diagram of the idea: no
boxes and arrows, no labelled slabs. A cache that skips work when nothing changed
is a pin-tumbler lock; a shutter is the two curtains in a camera. If the idea has
no mechanism, the figure will be weak; say so and pick another.

## Draw the context, or the object has no identity

**If the object's name depends on the machine around it, draw the machine.** A
lighthouse is self-contextualising: a tapered tower with a lantern is a
lighthouse. A shutter is not — two curtains in a frame read as a split door. The
first shutter figure here failed for exactly this, and the fix was not more
detail on the curtains: it was drawing the camera around them. Ask of any object:
*would a stranger name this from the drawing alone?* If not, what is the smallest
setting that names it?

## Find what gives it away

For each kind of part, name the **two or three features that make it what it is**,
each something the object would really have. A camera: a body with a lens of
concentric rings, a prism hump, a wind lever, a knurled knob. A lighthouse: a
taper, daymark bands, a lantern on top, a gallery round it. **A part with none of
them is a rounded block, and a row of rounded blocks is nothing in particular.**
Keep the list: it is the figures's `parts`, you draw from it, and the read checks
the small picture against it.

## The pointer and the slider

- The pointer sets the one thing the object is about: where it is sets a
  *position*, what it is over sets a *choice*. Read it in world units on a plane
  that never moves, so the hit does not chase the drawing.
- The slider is one number, `range`, at intensity 0, 0.5 and 1, that makes the
  answer weaker or stronger and moves one way only.
- If the object has a control — a knob, a lever, a dial — the mechanism moves it,
  so the interaction reads as caused, not scripted.

## The rest

What does the object look like when nobody touches it? It must already be a
composition, with one bright mark where the eye should start, and already say
what the figure is about. At rest the shutter is nearly closed; the reading is
the thumbnail.

## A weak concept

Drop it, or fix it, when: it is dead at rest; it needs a label to be understood;
it holds more than one idea; the pointer has no reason; it is a diagram; it is an
icon with nothing to answer with; it depends on colour; it will not read at 240px.
